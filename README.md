# Русификатор Le Mans Ultimate

Полная русификация Le Mans Ultimate: меню, гараж, настройки, лобби — и внутриигровой
слой: HUD, MFD (меню боксов), сообщения о флагах и штрафах, подсказки споттера.

Изменяются только файлы с текстом и шрифтами. Ни один `.exe`, `.dll` или скрипт игры
не патчится, в процесс игры ничего не внедряется.

## Что переведено

**Слой 1 — интерфейс** (`Bin\UI.zip`, React + i18next):

| Файл | Строк | Что это |
|---|---|---|
| `translation.json` | 1432 | весь текст интерфейса |
| `setting_descriptions.json` | 414 | названия и описания всех настроек |
| `banners.json` | 11 | баннеры DLC |
| `dlc-widget.json` | 9 | виджет DLC |

**Слой 2 — движок** (`Support\Languages`, gMotor):

| Файл | Строк | Что это |
|---|---|---|
| `english.dic` | 991 | HUD, MFD, флаги, штрафы, споттер, сообщения сервера |

Непереведёнными намеренно оставлены названия команд, трасс и технические строки
вроде `RC:-17.11mm AL:-21.02%` — они и должны быть на латинице.

## Установка

Нужен [Node.js](https://nodejs.org) (для сборки текстов) и, конечно, сама игра.
Игра при установке должна быть закрыта.

```powershell
# 1. Собрать тексты
node merge.js translation
node merge.js setting_descriptions
node merge.js banners
node merge.js dlc-widget
node build-en.js
node tools/dic.js keys
node merge-dic.js

# 2. Установить оба слоя
.\install.ps1        # интерфейс
.\install-hud.ps1    # HUD, MFD, сообщения движка (пересоберёт шрифты, ~25 мин)
```

Если игра стоит в другой папке — у каждого скрипта есть параметр `-GamePath`:

```powershell
.\install.ps1 -GamePath "D:\SteamLibrary\steamapps\common\Le Mans Ultimate"
```

**Язык в Steam менять не нужно.**

## Откат

```powershell
.\uninstall.ps1
.\uninstall-hud.ps1
```

Либо через Steam: Свойства игры → Установленные файлы → Проверить целостность.

## Как это устроено

### Интерфейс

Игра хранит интерфейс в `Bin\UI.zip`. Внутри — локали `start/locales/<язык>/`.
Русской локали нет, и функция `languageCodeFromGameLanguage` в `app-*.js` отправляет
`russian` в английский. Поэтому перевод кладётся в папку **уже существующей** локали:

- `locales/en/` — рабочий вариант, игра грузит его при английском языке в Steam;
- `locales/pl/` и `locales/ru/` — тот же перевод, но с полными формами множественного
  числа (1 пилот / 2 пилота / 5 пилотов). Правила ICU у польского совпадают с русскими,
  так что при переключении языка игры на Polski склонение чисел станет точнее.
  Минус: названия месяцев в расписании станут польскими.

### Движок

Строки движка переводятся словарём `Support\Languages\<язык>.dic` формата
`"английская строка" = "перевод"`. Игра читает файл по языку из Steam, поэтому русский
словарь ставится как `english.dic` (копия кладётся и в `russian.dic`).

### Шрифты

Ни в одном шрифте игры нет кириллицы — без замены был бы текст из пустых квадратов.

**Интерфейс.** Подменяются четыре файла, на которые ссылается `assets/fonts-*.css`:

| Оригинал | Замена |
|---|---|
| `Heebo-Regular-MSG.ttf` | Segoe UI |
| `Heebo-SemiBold-MSG.ttf` | Segoe UI SemiBold |
| `Antonio-SemiBold-MSG.ttf` | Bahnschrift |
| `Lexend-Black-removed-overlap.ttf` | Segoe UI Black |

Шрифты берутся из `C:\Windows\Fonts` вашей машины во время установки, в репозитории
их нет. Шрифт заголовков переключается: `.\install.ps1 -HeadingFont seguisb` (или `impact`).

**Движок** использует растровые атласы `.spritefont` (формат DirectX Tool Kit).
Их 641 штука, и все пересобираются с добавленным диапазоном кириллицы `0x400-0x45F`
утилитой `MakeSpriteFont.exe`, которую Studio 397 оставила в самой игре
(`Core\Shared\SpriteFonts\`) вместе с `BuildAll.bat`.

Параметры оригиналов восстановлены точно: пересборка **без** кириллицы даёт файлы,
побайтово идентичные оригинальным — так и проверялось, что параметры угаданы верно.

Шрифта `LMU` (основной шрифт HUD) в системе нет, поэтому для него подобрана замена —
Franklin Gothic Medium. Подбор не на глаз: `tools/idfont.js` читает метрики из `.spritefont`,
нормирует ширины символов на `M` и сравнивает с таблицами `hmtx`/`cmap` шрифтов-кандидатов.
Метод проверен на `ARIAL_*` — он корректно опознаёт в них `arial.ttf`.

## Про античит

Игра защищена Easy Anti-Cheat (EOS). Русификатор меняет только текст и шрифты:

- `Bin\UI.zip` — архив ресурсов интерфейса;
- `Support\Languages\english.dic` — обычный текстовый файл;
- `Core\Shared\SpriteFonts\*.spritefont` — растровые шрифты.

Ни один из этих файлов не входит в подписанные архивы: в `Core\Shared\shared.mft`
перечислены только `.mas`, и ни один `.mas` не изменяется. Инъекций в процесс,
хуков и правки кода нет — по характеру вмешательства это то же самое, что
пользовательская ливрея.

Гарантий при этом никто дать не может: проверяет ли EAC целостность файлов ресурсов,
знают только разработчики. Перед первым онлайн-заездом разумно проверить работу в офлайне.

## После обновления игры

Steam при обновлении перезаписывает изменённые файлы, и перевод слетает. Лечится
повторным запуском `install.ps1` и `install-hud.ps1`. Если в игре появились новые строки,
они останутся английскими, пока переводы не пересобраны — `node merge.js translation`
покажет, каких ключей не хватает.

## Структура

```
src/                       исходники перевода
  translation.part*.json         интерфейс
  setting_descriptions.part*.json
  banners.part01.json
  dlc-widget.part01.json
  translation.en-override.json   формы множественного числа для локали en
  dic/russian.part*.dic          словарь движка
tools/
  dic.js         разбор .dic, сбор списка ключей движка
  sfinfo.js      что за символы внутри .spritefont
  sfdump.js      подробный разбор структуры .spritefont
  sfscan.js      сводка по всем шрифтам движка и параметрам их сборки
  idfont.js      опознание шрифта по метрикам
  sfmetrics.js   сравнение метрик двух .spritefont
merge.js         склейка частей перевода со сверкой ключей
build-en.js      вариант локали en
merge-dic.js     склейка и проверка словаря движка
verify.js        проверка собранного UI.zip
build-fonts.ps1  пересборка шрифтов движка с кириллицей
install.ps1 / uninstall.ps1          интерфейс
install-hud.ps1 / uninstall-hud.ps1  движок
```

Все скрипты сборки проверяют результат: множество ключей должно совпадать с оригиналом,
подстановки вида `{driverName}` — сохраняться, кириллица в ключах `.dic` считается ошибкой.
