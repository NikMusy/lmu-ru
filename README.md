# Русификатор Le Mans Ultimate

Полная русификация Le Mans Ultimate: меню, гараж, настройки, лобби, регламент
онлайн-соревнований — и внутриигровой слой: HUD, MFD (меню боксов), сообщения о флагах
и штрафах, подсказки споттера.

Изменяются только файлы с текстом и шрифтами. Ни один `.exe`, `.dll` или скрипт игры
не патчится, в процесс игры ничего не внедряется.

## Что переведено

**Слой 1 — интерфейс** (`Bin\UI.zip`, React + i18next):

| Файл | Строк | Что это |
|---|---|---|
| `translation.json` | 1504 | весь текст интерфейса |
| `setting_descriptions.json` | 421 | названия и описания всех настроек |
| `banners.json` | 12 | баннеры DLC |
| `dlc-widget.json` | 4 | виджет DLC |
| `hardcoded-ru.json` | 31 | надписи, зашитые в бандл мимо системы перевода |
| `rules-ru.json` | 147 | регламент онлайн-соревнований и кодекс поведения |

**Слой 2 — движок** (`Support\Languages`, gMotor):

| Файл | Строк | Что это |
|---|---|---|
| `english.dic` | 1040 | HUD, MFD, флаги, штрафы, споттер, сообщения сервера |

Файлы локали покрыты полностью: `node merge.js <файл>` показывает 0 пропущенных ключей.

Непереведёнными намеренно оставлены:

- названия команд, трасс и машин;
- единицы измерения и технические строки вроде `RC:-17.11mm AL:-21.02%`, `psi`, `kPa`,
  `P1`, `LAN`, `ADSL 8M` — в языковых файлах самой игры они тоже везде на латинице;
- **политика конфиденциальности** (`Privacy`, ~25 000 знаков). Это юридический документ
  Motorsport Games, а не текст игры: официальной версией остаётся английская, и
  любительский перевод здесь способен ввести в заблуждение насчёт прав пользователя.
  Регламент соревнований — другое дело, его сама Studio 397 переводит на немецкий,
  французский, итальянский и испанский, так что русский встаёт в тот же ряд.

## Установка

Нужен [Node.js](https://nodejs.org) — только чтобы собрать тексты. Игра при установке
должна быть закрыта.

```powershell
# 1. Достать из игры оригиналы, с которыми сверяется перевод
node tools/extract-game.js

# 2. Собрать тексты
node merge.js translation
node merge.js setting_descriptions
node merge.js banners
node merge.js dlc-widget
node build-en.js
node tools/dic.js keys
node merge-dic.js

# 3. Установить оба слоя
.\install.ps1        # интерфейс
.\install-hud.ps1    # HUD, MFD, сообщения движка (пересоберёт шрифты, ~25 мин)
```

Папку игры скрипты находят сами: сначала смотрят переменную `LMU_PATH`, потом библиотеки
Steam из `libraryfolders.vdf`, потом обычные места. Если нужно указать явно:

```powershell
.\install.ps1 -GamePath "D:\SteamLibrary\steamapps\common\Le Mans Ultimate"
```

**Язык в Steam менять не нужно.**

Готовому пакету из [релизов](https://github.com/NikMusy/lmu-ru/releases) Node.js не нужен
вовсе: тексты в нём уже собраны, а надписи в бандле правит `patch-js.ps1`.

## Откат

```powershell
.\uninstall.ps1
.\uninstall-hud.ps1
```

Либо через Steam: Свойства игры → Установленные файлы → Проверить целостность.

## Как это устроено

### Интерфейс

Игра хранит интерфейс в `Bin\UI.zip`. Внутри — локали `start/locales/<язык>/`.
Русской локали нет, и функция `languageCodeFromGameLanguage` в `app-*.js` отправляет
`russian` в английский. Поэтому перевод кладётся в папку **уже существующей** локали:

- `locales/en/` — рабочий вариант, игра грузит его при английском языке в Steam;
- `locales/pl/` и `locales/ru/` — тот же перевод, но с полными формами множественного
  числа (1 пилот / 2 пилота / 5 пилотов). Правила ICU у польского совпадают с русскими,
  так что при переключении языка игры на Polski склонение чисел станет точнее.
  Минус: названия месяцев в расписании станут польскими.

### Надписи, зашитые в бандл

Часть текста выводится в `app-*.js` литералом:

```js
jsxRuntimeExports.jsx("p", { cohinline: "", children: "The chequered flag indicates the end of a race." })
```

Через файл локали такие строки не достать ни при каком языке — их правит `patch-js.ps1`,
заменяя литералы прямо в бандле. Замена точечная: только внутри `children`, `title`,
`placeholder` и `heading`, то есть там, где строка заведомо текст на экране, а не код.

Так же устроен и регламент соревнований: это компонент `CompetitionRulesEn` — 154 строки,
23 КБ текста. Рядом в бандле лежат его копии `CompetitionRulesEs`, `...De`, `...Fr`,
`...It` — Studio 397 переводит документ сама, но русской версии не сделала.
Найти новые зашитые строки после обновления игры: `node tools/findhardcoded.js`.

После замены скрипт проверяет себя: считает прирост размера и сверяет число фигурных
скобок до и после. В самих надписях фигурных скобок нет, поэтому изменившийся баланс
означал бы, что регулярка зацепила код, — тогда патч отменяется целиком.

### Движок

Строки движка переводятся словарём `Support\Languages\<язык>.dic` формата
`"английская строка" = "перевод"`. Игра читает файл по языку из Steam, поэтому русский
словарь ставится как `english.dic` (копия кладётся и в `russian.dic`).

### Шрифты

Ни в одном шрифте игры нет кириллицы — без замены был бы текст из пустых квадратов.

**Интерфейс.** Подменяются четыре файла, на которые ссылается `assets/fonts-*.css`:

| Оригинал | Замена |
|---|---|
| `Heebo-Regular-MSG.ttf` | Segoe UI |
| `Heebo-SemiBold-MSG.ttf` | Segoe UI SemiBold |
| `Antonio-SemiBold-MSG.ttf` | **Oswald SemiBold** (лежит в `src/fonts`) |
| `Lexend-Black-removed-overlap.ttf` | Segoe UI Black |

Шрифт заголовков — Oswald SemiBold: оригинальный Antonio очень узкий (0.445 em), и
системные шрифты с кириллицей заметно шире, из-за чего заголовки перестают помещаться.
Oswald узкий по своему рисунку (0.571 em), а не сжат механически, поэтому выглядит
аккуратно; лицензия OFL разрешает распространять его вместе с русификатором.
Если его почему-то нет, `install.ps1 -SystemHeadingFont` возьмёт системный шрифт и
сожмёт его по горизонтали через `tools/condense.js` — для этого запасного пути нужен Node.js.

Остальные шрифты берутся из `C:\Windows\Fonts` вашей машины во время установки.

**Движок** использует растровые атласы `.spritefont` (формат DirectX Tool Kit).
Их 641 штука, и все пересобираются с добавленным диапазоном кириллицы `0x400-0x45F`
утилитой `MakeSpriteFont.exe`, которую Studio 397 оставила в самой игре
(`Core\Shared\SpriteFonts\`) вместе с `BuildAll.bat`.

Параметры оригиналов восстановлены точно: пересборка **без** кириллицы даёт файлы,
побайтово идентичные оригинальным — так и проверялось, что параметры угаданы верно.

Шрифта `LMU` (основной шрифт HUD) в системе нет, поэтому для него подобрана замена —
Franklin Gothic Medium. Подбор не на глаз: `tools/idfont.js` читает метрики из `.spritefont`,
нормирует ширины символов на `M` и сравнивает с таблицами `hmtx`/`cmap` шрифтов-кандидатов.
Метод проверен на `ARIAL_*` — он корректно опознаёт в них `arial.ttf`.

## Про античит

Игра защищена Easy Anti-Cheat (EOS). Русификатор меняет только текст и шрифты:

- `Bin\UI.zip` — архив ресурсов интерфейса;
- `Support\Languages\english.dic` — обычный текстовый файл;
- `Core\Shared\SpriteFonts\*.spritefont` — растровые шрифты.

Ни один из этих файлов не входит в подписанные архивы: в `Core\Shared\shared.mft`
перечислены только `.mas`, и ни один `.mas` не изменяется. Инъекций в процесс,
хуков и правки кода нет — по характеру вмешательства это то же самое, что
пользовательская ливрея.

Гарантий при этом никто дать не может: проверяет ли EAC целостность файлов ресурсов,
знают только разработчики. Перед первым онлайн-заездом разумно проверить работу в офлайне.

## После обновления игры

Steam при обновлении перезаписывает изменённые файлы, и перевод слетает. Лечится
повторным запуском `install.ps1` и `install-hud.ps1`.

Если в игре появились новые строки, они останутся английскими, пока переводы не
пересобраны. Что проверить после обновления:

```powershell
node tools/extract-game.js        # обновить оригиналы из игры
node merge.js translation         # покажет, каких ключей не хватает
node tools/newkeys.js translation # выведет их готовым куском JSON
node tools/findhardcoded.js       # новые надписи, зашитые в бандл
node tools/newdic.js              # новые строки движка
```

Имена `app-*.js` и `*.css` собраны с хешами и меняются между версиями игры, поэтому
скрипты ищут их по маске и не привязаны к конкретной версии.

## Структура

```
src/                       исходники перевода
  translation.part*.json         интерфейс
  setting_descriptions.part*.json
  banners.part01.json
  dlc-widget.part01.json
  translation.en-override.json   формы множественного числа для локали en
  hardcoded-ru.json              надписи, зашитые в бандл
  rules-ru.json                  регламент соревнований и кодекс поведения
  dic/russian.part*.dic          словарь движка
  fonts/Oswald-SemiBold.ttf      шрифт заголовков (OFL)
lib/
  paths.js       корень репозитория и поиск папки игры
  zip.js         чтение записей из UI.zip без загрузки гигабайта в память
  icu.js         разбор ICU: имена аргументов для сверки подстановок
  game-path.ps1  то же, что paths.js, но для PowerShell-скриптов
tools/
  extract-game.js  достаёт из игры оригиналы в build/game
  dic.js           разбор .dic, сбор списка ключей движка
  findhardcoded.js надписи в бандле, которых нет в локали
  findkeys.js      ключи t(), которых нет в файле локали
  newkeys.js       ключи, появившиеся после обновления игры
  newdic.js        то же для словаря движка
  test.js          самопроверка lib/ и словарей
  sfinfo.js        что за символы внутри .spritefont
  sfdump.js        подробный разбор структуры .spritefont
  sfscan.js        сводка по всем шрифтам движка и параметрам их сборки
  idfont.js        опознание шрифта по метрикам
  sfmetrics.js     сравнение метрик двух .spritefont
merge.js         склейка частей перевода со сверкой ключей
build-en.js      вариант локали en
merge-dic.js     склейка и проверка словаря движка
patch-js.ps1     правка надписей, зашитых в бандл (Node не нужен)
verify.js        проверка собранного UI.zip
build-fonts.ps1  пересборка шрифтов движка с кириллицей
install.ps1 / uninstall.ps1          интерфейс
install-hud.ps1 / uninstall-hud.ps1  движок
make-release.ps1 сборка архива для раздачи
```

Оригиналы игры в репозитории не хранятся: `tools/extract-game.js` достаёт их из вашей
установки в `build/game`, и уже с ними сверяются все скрипты.

Все скрипты сборки проверяют результат: множество ключей должно совпадать с оригиналом,
подстановки вида `{driverName}` — сохраняться, кириллица в ключах `.dic` считается ошибкой.
`node verify.js` проверяет уже собранный `build\UI.zip`: ключи, подстановки, наличие
кириллицы в шрифтах и в бандле. `node tools/test.js` гоняет самопроверку вспомогательного кода.
